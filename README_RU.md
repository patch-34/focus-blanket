# Focus Blanket

[English](README.md) · **Русский**

Создаёт временный высокий трек с нейтральным медиаэлементом, перекрывающий содержимое области аранжировки при прослушивании.

## Работа скрипта

![Внешний вид](assets/ui.png)

- Первый запуск добавляет трек в начало проекта и создаёт длинный элемент, перекрывающий область аранжировки.
- Высота трека увеличивается до доступного размера окна (с учётом ограничений REAPER).
- Повторный запуск удаляет временный трек и восстанавливает выделение и временной диапазон просмотра.
- Не требует js_ReaScriptAPI.

Для поиска временного трека используются внутренние ключи сохранения состояния с историческим префиксом `Patch34`. Их изменение нарушило бы совместимость с уже сохранёнными проектами, поэтому они оставлены без изменений.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**, затем найдите **Focus Blanket** в **Browse packages**, установите и синхронизируйте пакет.

### Вручную

1. Скопируйте `Focus_Blanket.lua` в папку `Scripts` ресурсов REAPER.
2. Зарегистрируйте файл через **Actions → Show action list → New action → Load ReaScript**.
3. Запустите действие. Если необходимо, назначьте сочетание клавиш или кнопку панели инструментов.

При ручном обновлении сохраняйте путь и имя файла.
