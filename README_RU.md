# Focus Blanket

[English](README.md) · **Русский**

Focus Blanket — переключаемый Lua-скрипт для REAPER, создающий высокий трек с нейтральным медиаэлементом. Он временно закрывает детали области аранжировки, чтобы при прослушивании можно было сосредоточиться на звуке.

## Описание

Focus Blanket временно заменяет насыщенную деталями область аранжировки упрощённым представлением: один высокий трек в верхней части проекта и один длинный элемент нейтрального цвета, перекрывающий длительность проекта.

При повторном запуске скрипт удаляет созданный трек и восстанавливает прежнее выделение и временной диапазон области аранжировки.

**Основные задачи:**

- Скрыть визуальные детали проекта на время прослушивания.
- Показать нейтральное представление вместо множества треков и элементов.
- Вернуться к прежнему виду одним повторным запуском.

---

## Возможности

- Переключаемое действие: первый запуск включает Focus Blanket, повторный отключает.
- Создаёт один трек в начале проекта с именем `U ^ ェ ^ U`.
- Увеличивает высоту трека до области аранжировки (REAPER может ограничивать доступную высоту).
- Создаёт один длинный медиаэлемент по длительности проекта; если проект короче 30 секунд, используется минимальная длина 30 с.
- При отключении восстанавливает прежнее выделение и временной диапазон просмотра.
- Не требует js_ReaScriptAPI.
- Совместим с macOS и Windows.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**. Найдите **Focus Blanket** в **Extensions → ReaPack → Browse packages**, установите пакет и выполните синхронизацию.

### Вручную

1. Скопируйте `Focus_Blanket.lua` в папку `Scripts` ресурсов REAPER.
2. Откройте **Actions → Show action list → New action → Load ReaScript** и выберите файл.
3. Запустите зарегистрированное действие; при необходимости назначьте ему сочетание клавиш.

## Примечание о совместимости

Внутренние ключи состояния с прежним префиксом `Patch34` не изменены, чтобы не нарушить работу с существующими проектами. Удалять или переименовывать их вручную не требуется.
